     1→// ============================================================================
     2→// RMIS — Recruitment Management Information System (DOST-MIRDC)
     3→// Prisma schema mapping EXACTLY to the RMIS production SQLite database
     4→// (db/production-data.db) — the database is owned and accessed 100% by this
     5→// Next.js app via Prisma.
     6→//
     7→// IMPORTANT — READ BEFORE EDITING:
     8→//   * This schema is a PURE MAPPING. NEVER run `prisma db push` or migrations
     9→//     against the production DB — it would destroy real data.
    10→//   * Every model uses `@@map("table_name")` to map to the physical table.
    11→//   * Every field uses `@map("column_name")` to map to the physical column.
    12→//   * Legacy junction tables (`*_lnk`) are modelled as explicit join models (no Prisma
    13→//     `@relation` declarations) because they carry extra `*_ord` columns that
    14→//     Prisma's implicit m2m cannot represent.
    15→//   * DATE columns stored as TEXT ("1993-07-25") are typed as `String?`.
    16→//   * DATETIME columns stored as epoch milliseconds are typed as `DateTime?`.
    17→//   * JSON-typed SQLite columns are declared as `Unsupported("json")?`.
    18→//     DEVIATION from the task spec: Prisma 6.11's SQLite connector cannot
    19→//     deserialize SQLite `json`-declared columns — it throws
    20→//     "Conversion failed: Value json not supported" whenever a query returns
    21→//     a row with NULL in such a column. `Unsupported` makes Prisma skip the
    22→//     column entirely, so `findMany` works for all rows. To READ a json
    23→//     column's value, use `db.$queryRaw` (see `src/lib/raw-json.ts` helper).
    24→//     This matches the original Prisma introspection's choice.
    25→//   * `govt_id_date_issued` and `govt_id_valid_until` are varchar → `String?`.
    26→//   * Internal framework housekeeping tables (admin_*, strapi_*, i18n_locale,
    27→//     sqlite_sequence) are intentionally excluded — the app does not need them.
    28→// ============================================================================
    29→
    30→generator client {
    31→  provider = "prisma-client-js"
    32→}
    33→
    34→datasource db {
    35→  provider = "sqlite"
    36→  url      = env("DATABASE_URL")
    37→}
